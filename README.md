# Screenify

**A browser extension for managing screen time: block distracting sites and set your own rules. Beta version. Team project.**

## What it does

- Blocks chosen websites and shows a block page instead
- Options page to manage the block list and settings

## Stack

JavaScript, HTML, CSS, Chrome extension (Manifest)

## Try it

1. Download this repository
2. Open `chrome://extensions` and switch on Developer mode
3. Click **Load unpacked** and select the folder
